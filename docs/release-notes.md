# Vision Trends 1.0.0

首个基础功能版本：单篇/批量/会议论文采集、SQLite 论文管理、本地检索与在线回退、Top 10 热词、可点击关键词共现图谱、多年三会动态对比、年度榜单演变、CSV 导出及来源审计。

数据：2022—2025 八个会议届次的189篇官方样本，摘要来自 CVF / ECVA。所有年份、会议比较基于样本，不能代表会议整体。

环境：Node.js 22.13+，无第三方运行时依赖。默认本机写入；公网监听要求 ADMIN_TOKEN。Docker Compose 包含持久化卷与健康检查。

已知限制：受控词典覆盖有限；在线抓取依赖官网结构、网络与反机器人策略；单实例串行采集，单批最多30篇；无多用户账号。专用原型工具发布、CodeArts 远端 Release 和华为云部署仍需实际账号环境完成。
