# 人工阅读与验收任务卡

按任务卡实际操作，勾选后写出自己的解释。勾选代表本人完成，AI不会预先代勾。

## 1. 运行和探索（约15分钟）

- [ ] 启动应用，记录浏览器、Node版本和运行时间。
- [ ] 在总览选择CVPR/2024，核对样本数23篇。
- [ ] 点击Diffusion models，进入论文列表并打开一篇详情，核对官方来源。
- [ ] 切换热度占比和数量，解释为什么两个图形可能有差异。
- [ ] 解释ICCV 2024的“未举办”和CVPR某未采集年份的“未采集”有何不同。

## 2. 理解并修改（约30分钟）

- [ ] 阅读 `src/database.mjs`，说明唯一约束和绑定参数的作用。
- [ ] 阅读 `src/keywords.mjs`，选择一篇误分类或漏分类论文，提出真实修改。
- [ ] 对词典修改写一个输入/预期明确的测试，运行 `npm test`，提交本人commit。
- [ ] 阅读 `src/analytics.mjs`，用3篇小样本手算Top10和共现边权。
- [ ] 对照 `src/server.mjs`，复现清空标签后自动提取，解释原Bug。

## 3. 原型协作（约45分钟）

- [ ] 在Figma运行插件，确认10个画板和导航点击。
- [ ] 找到至少两处实际设计问题，发给AI讨论两个改法，再由本人选择。
- [ ] 实施修改，截取真实对话、修改前后、图层和交互设置。
- [ ] 发布原型并用另一个浏览器验证链接可访问。

## 4. Git与云端（根据账号环境记录实际时间）

- [ ] 创建学号项目，将现有真实历史推送CodeArts，不改写AI作者和时间。
- [ ] 用本人修改创建Issue/PR，dev合并main，发布1.0.0或后续版本。
- [ ] 部署到华为云，核对持久化卷和ADMIN_TOKEN，再外网访问。
- [ ] 截图源码、版本、部署过程并遮挡敏感信息。

## 5. 本人报告

- [ ] 补PSP实际时间，分析最高的一项偏差。
- [ ] 阅读《构建之法》第3/4/8章，用自己的话连接需求、结对与审阅。
- [ ] 完成3个真实人机案例，区分AI自行修复和本人发现问题。
- [ ] 写个人心路历程与评价，删除博客草稿中的提示语和占位内容后再发布。

## 口头解释练习

1. 为什么一个关键词在摘要出现10次只算1篇？
2. 为什么47篇3D vision不能直接说明它占全部CVPR/ICCV/ECCV论文的比例？
3. 为什么不从DBLP“补一个”摘要？
4. 为什么重采集不覆盖已有记录？如果想更新官方摘要，会怎样设计更安全？
5. 单用户口令有哪些局限？如果多人使用，数据库和授权要如何改变？
6. 原型工具和程序之间是什么关系？为何不能直接用原型导出代码交作业？
