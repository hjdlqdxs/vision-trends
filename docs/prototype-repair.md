# 专用原型交互迭代：人工发现问题，AI批量修复

## 已发生的人工反馈

1. 用户在Figma Desktop运行原型生成插件，截图确认10张原生画板创建。
2. 用户发现插件长期Running，后来报告自动停止；不能据此断言所有连线成功。
3. 用户进入原型预览，反馈论文库缺少返回入口、侧栏研究总览未跳转。
4. 用户按照指导手动绑定交互，发现只有文字可点；将点击目标改到整个Frame后确认“现在可以了”。
5. 用户继续检查，反馈“有好多跳转都无法完成”，请求AI直接协助操作。

## AI实际处理

本会话没有可调用的Figma桌面控制工具，未冒称远程点击。改为更新用户已经导入的本地开发插件，用户运行一次即可在Figma内批量执行。

旧版恢复代码遇到任意已有reaction即跳过，并未核验目标；缺失/错误导航和子文字点击冲突需要更完整的检查。新版按现有页面与按钮识别预期目标，保留正确连接，修正已知错误点击，保留其他触发类型。为独立文字入口补点击区域，为论文库和结果页补缺失的返回按钮；重复运行不重建画板。

新版结果窗口会报告成功和失败，失败不自动包装成完成。单条接口超时后继续其余条目；进度窗口保持打开直到用户关闭，避免瞬间消失的错误提示难以截图。

## 验证边界

7项模拟Figma场景测试通过，验证源文件在模拟环境生成所有画板和预期导航，并覆盖部分失败恢复。代码语法检查通过。用户真实文件中的实际读取、图层命名或分组修改、接口响应速度与渲染仍待执行结果确认。

学生贡献：运行专用工具、提供截图、发现并手工修正点击范围、继续测试并提出批量修复需求。

AI贡献：代码诊断、自动修复实现、模拟测试、执行说明。

待补证据：修复窗口结果截图、重新预览后的关键路径、原型分享链接。没有把AI测试结果写成人工已全部验收。
