# 人工反馈案例：筛选后进入论文列表，缺少返回入口

## 实际发生的过程

用户已运行项目、浏览交互，并报告：选择会议类型后，点击热门研究方向进入论文库，无法直接返回上一级。

AI检查源码确认：旧版链接保留了查询筛选，却没有记录来源，也没有在论文库提供返回按钮。问题影响研究总览Top10、共现图谱和年度榜单中的词条跳转。

修复采用显式来源链接，而不是直接调用浏览器历史后退。原因是用户可能在列表里翻页、搜索或刷新，此时“浏览器上一页”未必是原总览。来源链接只允许内部总览/年度页，并保留原会议和年份。

## 实现结果

- 论文资料库顶部新增“← 返回研究总览”入口。
- 从年度演变进入时显示“← 返回年度演变”，返回进入列表时选中的年份。
- 在列表里搜索、翻页、切换关键词后仍能返回原始页面。
- “清除”关键词保留会议和年份，页码重置。
- 旧版链接没有来源参数时，按当前会议/年份返回总览。
- 6项导航测试加16项原有测试，共22项通过；源码语法检查通过。

## 请用户现在亲自复验

1. 在浏览器按 Ctrl+F5 刷新，加载更新后的脚本。
2. 打开研究总览，选择 CVPR 和 2024。
3. 点击任意热门方向，在论文库顶部确认出现“← 返回研究总览”。
4. 点击返回，确认仍是 CVPR / 2024，样本数23篇。
5. 再通过图谱进入论文库；清除关键词后，确认会议/年份仍在；返回后仍保留原筛选。
6. 可选：年度演变选择 ECCV / 2024，点击词条，再返回，确认年度不重置。
