## 在 Figma Desktop 创建可编辑原型

1. 登录自己的 Figma，在 Design 新建空白文件。
2. 菜单 Plugins → Development → Import plugin from manifest，选择本目录 `manifest.json`。不同 Figma 版本菜单名称可能不同，以实际界面为准。
3. 运行 **Vision Trends Course Prototype**。插件使用 Figma 原生 Frame、Rectangle、Text 创建10张画板、侧栏导航、图谱点击和论文管理跳转；不访问网络。
4. 如 Inter 字体缺失，在 Figma 中启用/安装该字体；中文使用 Figma 的系统回退字体。实际运行效果需要在本人账号复核。
5. 根据 `docs/requirements.md` 和下表，**人工调整至少两处真实问题**，截图修改前后并记录理由。推荐重点复核图谱可读性、空结果状态和原型按钮交互。
6. Prototype 面板选择总览画板为 flow starting point；运行 Present，逐项检查导航和返回路径。
7. 使用 Share prototype 获取可访问网页链接；确认助教可以访问。将实际分享链接填入博客。若工具权限限制分享，使用学校认可的其他工具并保留操作证据。

这份插件只生成设计稿；应用源码在 `src/` 和 `public/`，**没有使用原型工具生成程序代码**。原型草稿不包含真实查询引擎，搜索按钮指向示例结果，动态播放按钮演示页间状态切换；正式动态统计由应用实现。

## 页面和交互规范

| 页面/状态 | 入口 | 交互与结果 | 人工需核验 |
|---|---|---|---|
| 总览 | 默认起点 | Top10/图谱节点→关键词结果；侧栏跳转 | 图谱信息密度与标签重叠 |
| 论文库 | 侧栏/返回 | 标题→详情；编辑→表单；删除→确认；搜索→结果 | 筛选与返回路径 |
| 采集 | 侧栏 | 单篇/批量/目录；提交→论文库状态 | 需补加载/部分失败帧以提高交互完整度 |
| 趋势 | 侧栏 | 指标/方向选择；播放按钮→年度展示状态 | 正式图表动效以成品为准 |
| 年度榜单 | 侧栏 | 年份滑块/播放；词条→结果 | 年度状态可增加更多画板 |
| 关于 | 侧栏 | 会议、来源、公式和偏差说明 | 用实际理解校订文案 |
| 详情 | 标题 | 摘要、来源、编辑、返回 | 正确区别官方摘要与提取标签 |
| 编辑 | 新增/编辑 | 必填校验说明；保存/取消返回 | 可用 Figma overlay 改善弹窗体验 |
| 删除确认 | 删除 | 确认/取消回库 | 危险操作视觉层级 |
| 关键词结果 | 图谱/搜索 | 保留筛选，进入详情 | 原型示例数据不作为真实统计 |
